# GenGate 0.9.8 Beta

Windows x64 add-on for official **PhotoCraft 0.20.2**.

- Studio is now a floating palette: drag it beyond the editor window or onto another monitor. Its position and size are remembered.
- Added **Custom** output dimensions with X, Y and Save. The saved dimensions appear in bold in the aspect-ratio list.
- Removed the Seed button and its dialog from Studio.
- Generating again keeps your original references. To use a generated image as a reference, drag its layer into a reference slot.
- Restoring a generated layer restores its generation settings, including dimensions.
- Made interrupted installations and updates recoverable while preserving existing settings.

Close PhotoCraft, extract the complete GenGate ZIP and run **Setup.cmd**. For an update, select your existing PhotoCraft and GenGate folders. Install model files separately.
