# GenGate 0.9.7 Beta

Windows x64 add-on for official **PhotoCraft 0.20.1**.

- Redesigned Setup as a frameless dark window in PhotoCraft's Studio style.
- Fixed Browse failing to open when its path field is empty. Paths remain editable if the file browser cannot open.
- Fixed a false installation failure after a successful install. Setup now clearly distinguishes success, optional setup notes and an installation error.

Close PhotoCraft, extract the complete GenGate ZIP and run **Setup.cmd**. For an update, select your existing PhotoCraft and GenGate folders. Install model files separately.
