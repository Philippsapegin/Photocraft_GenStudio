# GenGate 0.10.1 Beta II

Windows x64 add-on for official **PhotoCraft 0.22.0**.

- Install and update as your normal Windows user. Setup prepares a personal PhotoCraft copy for protected installations and keeps your profile and model folders.
- Fixed installation failures with PhotoCraft's large default preferences, inaccessible runtimes from another account, and stale runtime paths. Access errors now identify the affected file.
- Direct now uses a model-independent runtime folder. Existing private runtimes migrate without another dependency download; external Python installations stay in place.
- Taller setup window with all options visible without scrolling. If PhotoCraft is missing, setup opens the matching download page.
- Removal works from the complete extracted ZIP, with optional verified recovery-backup cleanup and a separate restore step for old system-wide installations.

Save your documents and close PhotoCraft. Extract the complete ZIP and run **Setup.cmd** normally, without **Run as administrator**. For an update, select your existing GenGate folder. Model weights are not included.
