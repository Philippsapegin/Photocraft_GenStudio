# Исправления после аудита: материалы для ревью

Материалы первоначального ревью изменений поверх `da4915d` / GenGate 0.9.7. Первичные проверки проводились до коммита и публикации, без замены пользовательской установки PhotoCraft.

## Что изменено

- **A01 — повтор установки.** Setup записывает владельца незавершённой подготовки до копирования runtime. После ошибки загрузки или отмены следующая попытка использует свою незавершённую папку. Посторонние файлы не удаляются. Готовый runtime повторно как staging не используется.
- **A02 — согласованный откат.** Launcher, uninstall, итоговая metadata, настройки, оба exe и состояние патча входят в общий журнал. Ошибка записи возвращает предыдущие файлы; после аварийного завершения тот же журнал восстанавливается перед новой попыткой. Старый формат журнала поддерживается. Подготовленные runtime остаются для повтора; ярлыки и проверка наличия моделей выполняются после commit и дают отдельные примечания.
- **A03 — сохранение настроек.** Обновление переносит полный валидированный набор настроек. Нестандартный порт ComfyUI, Python обоих движков, startup, presets, Constant LoRA и workflow сохраняются. Пустое скрытое поле папки ComfyUI при установке Direct не очищает сохранённый путь. Заменяются поля запроса и путь нового runtime. При смене общей папки моделей прежние плоские пути encoder/VAE очищаются, как и раньше. Выбор ярлыка подхватывается из предыдущей установки.
- **A04 — seed.** Фактический seed каждого результата проходит из Direct в метаданные своего слоя и сохраняется в документе. Кнопка и диалог Seed удалены по запросу пользователя для 0.9.8. Внутренний seed и метаданные сохранены. Восстановление конкретного слоя использует seed этого изображения.
- **A05 — восстановление.** В слое сохраняется движок; восстановление возвращает Direct/preset или ComfyUI/workflow, промпты, LoRA, точные размеры и seed. Для старых слоёв с workflow выбирается ComfyUI; для старых Studio-слоёв без workflow — Direct. Отсутствующие старые seed восстановить невозможно: они остаются random. Перетаскивание слоя в основной слот по-прежнему явно добавляет его изображение как исходник.
- **Повтор генерации.** Результат не подставляется в основной референс. Пустой слот остаётся пустым; добавленные пользователем референсы сохраняются. Обычный Generate использует прежние условия, с новым seed в режиме random.
- **Custom.** В списке соотношений есть Custom. Выбор сразу открывает окно X/Y и Save в стиле настроек LoRA. После сохранения строка показывает размеры, например **768px:512px**, шрифтом Inter SemiBold. Повторный выбор открывает редактирование. До Save и при закрытии без сохранения действующие размеры не меняются. С исходным изображением список предлагает Source (соотношение исходника) и Custom (точные пиксели); без изображения доступны обычные соотношения и Custom. Проверяются пределы и сетка выбранного движка: Qwen — 32 px, FLUX/FIBO — 16 px, workflow — 1 px.

## Свободная палитра Studio

По следующему запросу реализована системная палитра без переключателя отделения. Заголовок перемещает её за границы PhotoCraft; состояние Studio и сессия остаются общими. Оформление и связанные окна используют тот же интерфейс редактора. Подробности и отдельные проверки — [FLOATING_PALETTE.md](FLOATING_PALETTE.md). Копия для ручного ревью запускается через `.runtime/palette-candidate/Review-Palette.cmd` с отдельным профилем и синтетическим backend.

Используется `show_viewport_immediate` и небольшой безопасный callback создания окна в локальной копии закреплённого eframe. Это позволяет сразу задать владельца Windows, сохранив скрытие со свёрнутым редактором и отсутствие отдельной кнопки на панели задач. Координаты слоя переводятся через физические пиксели рабочего стола; файловый drop и текстовый ввод обрабатываются в viewport Studio. Результаты проверок этой задачи хранятся отдельно от исходного аудита: `.runtime/palette-*`.

## Первичная проверка аудита

Используются только временные каталоги, искусственные exe/дельты, синтетические изображения и backend без моделей. Проверки GPU-инференса не выполняются. Результаты нативных проверок и отдельной сборки для ревью находятся в `.runtime/review010-*`.

- Python: 203 проверки, 191 прошла, 12 пропущены из-за необязательных зависимостей.
- Engine: 2717 прошли, 16 ignored; UI: 4707 прошли, 21 ignored.
- После окончательной правки начертания повторно прошли Clippy и 38 профильных UI-тестов.
- Дополнительно: Clippy с `-D warnings`, зависимости слоёв, WASM (24 crates и HEIF), adversarial `panic_hunt` — без ошибок.
- Проверена идентичность трёх изменённых Rust-шаблонов подготовленным исходникам после штатных преобразований и форматирования.
- Setup: отказы записи на каждой границе commit, первая установка и обновление, повтор после отмены/сбоя зависимостей, восстановление журнала после прерывания, удаление после прерванного обновления, сохранение настроек и защита готового runtime при неудачной очистке маркера.
- Custom: открытие из списка, Save, повторное редактирование, отмена, недопустимые значения, сохранение состояния; отдельный визуальный снимок диалога.
- Готовые exe: синтетическая генерация без референсов, фиксация seed через UI и повтор без добавления изображения, точные 768×512, восстановление Direct после ComfyUI. Расширенный прогон проверяет референсы, batch и seed каждого слоя, Undo/Redo, `.pcraft`, 24 MP референс и отмену.
- Визуально проверены тёмная и светлая Studio, жирный размер Custom, Source с референсами, диалог X/Y и окно seed. Снимки — `.runtime/review010-screenshots/`.

Сводный отчёт: `.runtime/review010-native.json`. Проверенные exe: `.runtime/review010-candidate/`. Установленная пользовательская копия PhotoCraft не заменена.
