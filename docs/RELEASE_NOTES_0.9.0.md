# GenGate 0.9.0 — Beta 1

The first GenGate beta brings preset-based component selection, native AI editing tools and a compact generation workspace to PhotoCraft.

- Qwen Image 2.1 and FLUX 3 presets, with automatic discovery and separate Advanced component choices.
- Browse for model, encoder, VAE, FLUX prompt upsampler and optional Constant LoRA. Adapter strength is configurable; Constant LoRA applies only to Ai Fill and Remove Brush.
- Independent AI selection engine, native tool integration, queued masked edits and layer variants.
- Restored title band, compact chip and smooth window dragging. Settings remain in Preferences.

Download the Windows ZIP, extract it completely and run **Setup.cmd**. To update an earlier installation, save and close its editor and choose the same destination. Models are separate and can be reused from ComfyUI. See the [README](https://github.com/Philippsapegin/Photocraft_GenStudio/blob/v0.9.0/README.md) for setup and model files.

This is a WIP beta; ComfyUI integration is experimental. Validation covers synthetic generation, native controls and installation. Real model inference, image quality and memory use have not been validated for this release. Windows x64, unsigned, based on PhotoCraft 0.8.2; independently maintained.
