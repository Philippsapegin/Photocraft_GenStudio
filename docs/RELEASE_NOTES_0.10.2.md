# GenGate 0.10.2

Windows x64 add-on for official **PhotoCraft 0.23.1**.

The selection prompt bar now opens at its compact size instead of covering small selections. It stays out of the way while you drag on the canvas.

Save your documents and close PhotoCraft. Extract the complete ZIP and run **Setup.cmd** as your normal Windows user. For an update, select your existing GenGate folder; your settings and model folders are preserved. Setup can update an older PhotoCraft before installing GenGate.

Model weights are not included.
