# GenGate 0.10.0 Beta II

Windows x64 add-on for official **PhotoCraft 0.21.0**.

- Redesigned setup with a cleaner PhotoCraft-style window, fixed Browse buttons and reliable completion messages. Uses the existing PhotoCraft shortcuts without an extra GenGate desktop shortcut.
- Updates recover your existing folders and engine settings and reuse an installed Direct runtime. Direct is enabled by default; a single checkbox allows a ComfyUI-only installation.
- PhotoCraft can update again after installing GenGate, including copies that previously refused updates because the editor was unsigned. Setup guides you through the supported update and preserves your settings.
- Ai Fill keeps more source context for edit models and blends the selection edge more smoothly. Includes tested FLUX3 and aligned FIBO ComfyUI workflows.
- Real generation paths checked with Qwen Image 2.1 Turbo, FLUX3 Klein and FIBO 2 Edit Turbo; Explorer LoRA wiring checked with Anima and Stein.

Save your documents and close PhotoCraft. Extract the complete ZIP and run **Setup.cmd**. For an update, use your existing PhotoCraft and GenGate folders; setup restores the saved paths and settings. Model weights are not included.
